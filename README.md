# 💱 Currency Converter Web App

A simple and responsive Currency Converter built using **HTML, CSS, and JavaScript** with real-time exchange rates using an API.

## 🚀 Features

- Convert between different currencies
- Real-time exchange rates using API
- Clean and responsive UI
- Easy to use interface
- Supports multiple currencies

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Currency Exchange API


## ⚙️ How It Works

1. Select the base currency
2. Select the target currency
3. Enter the amount
4. The app fetches live exchange rates from the API
5. Displays the converted value instantly
